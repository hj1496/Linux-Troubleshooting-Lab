# BF 1-1. CPU 사용률 이상 — 반복 실행 프로세스 추적

## 1. 개요

| 항목  | 내용                                                         |
| --- | ---------------------------------------------------------- |
| 환경  | Rocky Linux 8.10 (`node1`)                                 |
| 문제  | CPU 부하를 발생시키는 프로세스의 원인 파악                                  |
| 진단  | `top`, `vmstat`, `ps`, `pstree`, `jobs`로 부하와 프로세스 실행 관계 확인 |

## 2. 문제 현상

- CPU 부하가 발생하여 원인 프로세스를 조사했다.
- `sha256sum`과 `sleep`이 반복 실행되는 작업이 확인되었다.

## 3. 원인 분석

### ① CPU 상태 확인

```bash
top
vmstat 1 5
```

CPU 사용 상태를 확인한 뒤 프로세스 조사로 범위를 좁혔다.

### ② 프로세스 실행 관계 추적

```bash
ps
pstree
jobs -l
```

프로세스 관계를 추적한 결과, 백그라운드에서 실행된 Bash 반복 작업이 원인이었다.

확인된 반복 작업의 내용:

```bash
while :; do
    sha256sum /usr/bin/bash > /dev/null
    sleep 0.05
done
```

반복문이 `sha256sum`과 `sleep`을 계속 실행하면서 CPU 부하를 발생시켰다.

## 4. 해결 과정

- 원인이 된 백그라운드 작업을 종료했다.
- `top`과 `vmstat`으로 CPU 상태를 다시 확인했다.

## 5. 결과

- 백그라운드 반복 작업 종료 후 CPU 부하가 해소되었다.
- CPU idle 비율이 약 **96~98%**로 회복된 것을 확인했다.
